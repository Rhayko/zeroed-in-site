I built ZeroedIn Performance Lab to help athletes and military or tactical personnel organize daily state, sleep, training, and repeatable performance testing in one transparent system. The goal is to understand individual patterns without turning limited data into false certainty.

Purpose

What I designed it to do

The lab brings together context that is usually scattered across notebooks and apps. It builds an individual baseline, shows rolling trends and deviations, summarizes training load, and surfaces exploratory relationships that may be worth investigating.

Descriptive findings are labeled as descriptions. Associations are treated as exploratory rather than causal. Predictive outputs are reserved for later models that can be tested against recorded outcomes.

Milestone 1 includes

  • Athlete or tactical profile
  • Daily check-in and sleep context
  • Exercise, set, rep, load, RPE and RIR logging
  • Repeatable performance tests
  • Individual baselines, trends and deviations
  • Training-load summaries
  • Scientific Claims Register
  • Demo data, backup and restore

Workflow

How I use the lab

  1. Create a private local workspace or explore the fictional demo.
  2. Record daily context and completed training consistently.
  3. Add repeatable performance tests under similar conditions.
  4. Let the baseline develop over roughly 28 days.
  5. Use trends as prompts for review—not diagnoses or commands.
  6. Export a backup before moving or clearing the workspace.

Build

How it works

I built the interface in React and TypeScript, the API in Python with FastAPI, and the analytics as transparent Python calculations. Persistence is cleanly separated so local SQLite development can move to PostgreSQL later.

Automated tests cover important calculations and API behavior. A continuous-integration workflow rebuilds and retests the project whenever code is published.

Boundaries

What this version does not claim

This V1 does not diagnose injury, determine deployment or duty status, replace medical or command judgment, infer causation from correlations, or predict future performance. Its value is disciplined observation: helping me describe what has happened, compare it with an individual’s own history, and document exactly how each metric should be interpreted.
