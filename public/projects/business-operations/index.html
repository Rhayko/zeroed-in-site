A margin review before a budget increase.

Sales can conceal losses

Paid social produces $56,133.30 in net sales and −$14,952.42 in contribution after marketing. Revenue-only reporting would miss that gap.

Returns deserve investigation

Paid social has a 26.28% unit-return rate versus roughly 10% elsewhere. In this simulation, higher returns and deeper discounts are deliberately encoded assumptions.

Attribution is unresolved

Direct contributes $21,637.02, but has no allocated marketing cost. This does not prove direct acquisition is free or that shifting budget will reproduce its margin.

Recommended next decision: investigate discount depth, return reasons and acquisition costs before increasing paid-social spend. A real budget change requires incremental-demand evidence and a controlled test; this synthetic analysis does not establish causality.

Six tables. Three controlled grains.

Line grain

Aggregate returns first.

Several return events can reference one order line. Summing sales after that raw join would repeat the original sale. The first SQL view reduces returns to one row per line.

Order grain

Charge fulfillment once.

Line economics roll up to each order before its fulfillment cost is deducted. Multi-item baskets do not multiply shipping costs.

Channel-month grain

Keep spend visible.

A union of sales and spend keys preserves marketing expense even in a month with no orders. Spend is deducted once, with no arbitrary product allocation.

Reproduce the decision trail.

The package contains the six source-table CSVs, SQLite database, schema and analytical views, five SQL investigations, generator, test suite and dashboard-ready exports. Sixteen automated checks include independent reconciliation, reproducibility, partial/full returns and spend-only months.

Each return belongs to its original order cohort. This is not a cash-flow statement or refund-month accounting report. Every cohort has a complete 30-day simulated return window.
